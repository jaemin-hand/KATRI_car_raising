# KATRI 고주로 시험 보조 앱

KATRI 고주로 반복 주행 시험을 보조하기 위한 Android 앱입니다.

## 현재 범위

- 앱 시작 화면
- 큰 버튼 2개
  - 시험 준비
  - 고주로 주행
- 시험 준비 화면
  - 차량 선택
  - 시험 방식 선택
  - 시작 ODO 입력
  - 시작 전 촬영/점검 체크리스트
  - VBOX/GPS 장착 확인 스킵
- 고주로 주행 화면
  - 타원형 고주로 미리보기
  - 현재 속도
  - 이번 세션 거리
  - 전체 누적 거리
  - 랩카운트
  - 스타트 지점 지정/주행 제어 버튼

## 기술 방향

- Kotlin Android
- 백엔드 없음
- GPS 기반 속도/거리 기록
- 고주로 타원 영역 제한
- 스타트 지점 기반 랩카운트
- 차량 종류별 시험 방식 반영
